# IPL Match Analysis

An exploratory data analysis project on IPL match data using Python, Pandas, and Matplotlib.  
The project focuses on team performance, toss impact, chasing trends, venue patterns, and winning margins.

## Project Overview

This project analyzes IPL match-level data to answer questions such as:

- Which teams have the highest win rate?
- Does winning the toss affect match results?
- Are chasing teams more successful?
- Which venues are more favorable for teams?
- Which teams have the biggest victory margins?

## Dataset

The dataset contains IPL match information such as:

- Match teams
- Winner
- Toss winner
- Toss decision
- Venue / city
- Win by runs
- Win by wickets
- Player of the Match

## Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Insights

- Mumbai Indians and Chennai Super Kings showed strong overall performance across seasons.
- Toss outcomes had limited influence compared to overall team strength.
- Chasing was often a successful strategy in several matches.
- Some venues showed a clear pattern in match outcomes.
- A few players repeatedly stood out as Match Winners.
